# Artist Rider Contract Template for Ologywood Booking Platform

## Overview

This document provides a comprehensive rider contract template designed specifically for the Ologywood artist booking platform. A rider is a formal document that outlines an artist's technical, hospitality, and contractual requirements for a performance. This template simplifies the booking process by providing clear, standardized fields that both artists and venues can use to establish expectations and prevent misunderstandings.

## Purpose and Benefits

**For Artists:** A well-documented rider ensures that venues understand technical requirements, hospitality needs, and performance specifications, reducing the risk of inadequate setup or unsatisfactory working conditions.

**For Venues:** A clear rider helps venues plan logistics, allocate resources appropriately, and understand exactly what to expect from the artist, enabling better event management and audience experience.

**For Ologywood:** Standardized riders streamline the booking workflow, reduce communication overhead, and create a professional framework that builds trust between artists and venues.

## Rider Contract Template Structure

### 1. Event Details Section

This section captures the fundamental information about the performance event.

| Field | Description | Example |
|-------|-------------|---------|
| Event Name | Title of the event or concert | Summer Music Festival 2026 |
| Event Date | Scheduled date of performance | 2026-06-15 |
| Event Time | Start time of the event | 19:00 (7:00 PM) |
| Venue Name | Name of the performance location | The Grand Theater |
| Venue Address | Full address including city and postal code | 123 Main St, New York, NY 10001 |

**Usage:** These fields establish the basic context and logistics for the booking. The venue should provide accurate information to ensure the artist can plan travel and preparation accordingly.

### 2. Artist Requirements Section

This section defines the artist's performance specifications and compensation.

| Field | Description | Example |
|-------|-------------|---------|
| Artist Name | Legal name or stage name of performing artist/band | The Jazz Collective |
| Performance Fee | Agreed-upon compensation for the performance | $2,500 |
| Performance Duration | Total time allocated for the performance (in minutes) | 90 minutes |
| Sound Check Time | Required time before performance for technical setup | 1 hour before |

**Usage:** These fields establish clear expectations about compensation, performance length, and technical preparation time. Sound check time is critical for ensuring proper audio levels and equipment testing.

### 3. Technical Requirements Section

This section outlines all equipment and technical specifications needed for a professional performance.

| Field | Description | Example |
|-------|-------------|---------|
| Stage Size | Dimensions or description of the performance stage | Medium (20x20 feet) |
| Professional Lighting Required | Whether professional stage lighting is needed | Yes |
| Sound System Provided by Venue | Whether the venue provides PA/sound equipment | Yes |
| Backline Equipment | Musical instruments and amplification provided by venue | Drum kit, Bass amp, Guitar amp, Keyboard |

**Usage:** Technical requirements ensure the venue can accommodate the artist's equipment needs and provide necessary infrastructure. This prevents situations where artists arrive expecting equipment that isn't available.

**Common Backline Equipment:**
- Drum kit with hardware
- Bass amplifier and cabinet
- Guitar amplifier and cabinet
- Keyboard amplifier
- Microphone stands and cables
- Monitor speakers
- Mixing console

### 4. Hospitality Requirements Section

This section specifies the artist's comfort and logistical needs during the event.

| Field | Description | Example |
|-------|-------------|---------|
| Dressing Room Required | Private space for artist preparation | Yes |
| Meal Provision | Type and timing of meals provided | Catered meals for all band members |
| Parking Provided | Dedicated parking for artist vehicles | Yes |
| Security Required | Security personnel for artist safety | Yes |
| Guest List Allowed | Number of complimentary tickets for artist's guests | 5 guests |

**Usage:** Hospitality requirements ensure the artist feels valued and can perform at their best. Professional venues understand that proper accommodations directly impact performance quality.

**Best Practices:**
- Dressing rooms should include mirrors, seating, and climate control
- Meals should accommodate dietary restrictions (provide options for vegetarian, vegan, gluten-free, etc.)
- Parking should be convenient and secure
- Security needs vary based on artist profile and venue size

### 5. Additional Terms Section

This section covers contractual and policy details that govern the booking.

| Field | Description | Example |
|-------|-------------|---------|
| Cancellation Policy | Terms for cancellation and refund conditions | 50% refund if cancelled more than 30 days before event; 25% if cancelled 7-30 days before; no refund if cancelled less than 7 days before |
| Additional Notes | Any special requirements or unique circumstances | Artist requires wheelchair accessible entrance; no flash photography during performance |

**Usage:** These fields establish legal and operational boundaries, protecting both parties. Clear cancellation policies prevent disputes and establish professional expectations.

## Implementation Guide for Ologywood Platform

### For Artists Creating Riders

1. **Create a Master Rider:** Artists should create a comprehensive rider that covers all their standard requirements. This becomes their default template.

2. **Customize per Event:** For specific bookings, artists can modify their master rider to reflect unique venue conditions or event requirements.

3. **Share with Venues:** Once finalized, the rider should be shared with the venue contact person for review and acceptance.

4. **Document Acknowledgment:** Keep records of venue acknowledgment to ensure all parties agree to the terms.

### For Venues Reviewing Riders

1. **Review Feasibility:** Assess whether the venue can meet all technical and hospitality requirements.

2. **Identify Gaps:** If the venue cannot meet specific requirements, communicate this clearly and propose alternatives.

3. **Confirm in Writing:** Send a written confirmation of all agreed-upon terms to the artist.

4. **Prepare Resources:** Allocate budget and staff to ensure all requirements are met on event day.

### For Ologywood Platform Integration

The RiderContractTemplate component provides:

- **Edit Tab:** Allows artists to create and modify rider contracts with intuitive form fields
- **Preview Tab:** Shows how the rider will appear as a formatted document
- **Download Function:** Generates a text file that can be printed or shared via email
- **Save Functionality:** Stores rider templates in the database for future use and modification

## Sample Rider Contract

```
ARTIST RIDER CONTRACT
=====================

EVENT DETAILS
Event Name: Summer Music Festival 2026
Date: June 15, 2026
Time: 19:00 (7:00 PM)
Venue: The Grand Theater
Address: 123 Main St, New York, NY 10001

ARTIST INFORMATION
Artist Name: The Jazz Collective
Performance Fee: $2,500
Performance Duration: 90 minutes
Sound Check Time: 1 hour before performance

TECHNICAL REQUIREMENTS
Stage Size: Medium (20x20 feet)
Lighting Required: Yes - Professional stage lighting with color mixing capability
Sound System Provided: Yes - Full PA system with monitor speakers
Backline Equipment: Drum kit, Bass amp, Guitar amp, Keyboard amp

HOSPITALITY REQUIREMENTS
Dressing Room Required: Yes - Private room with mirror and seating for 5 people
Meal Provision: Catered dinner for all band members (accommodate vegetarian options)
Parking Provided: Yes - Secure parking for 2 vehicles
Security Required: Yes - 2 security personnel
Guest List Allowed: 5 complimentary tickets

ADDITIONAL TERMS
Cancellation Policy: 50% refund if cancelled more than 30 days before event; 25% if cancelled 7-30 days before; no refund if cancelled less than 7 days before
Additional Notes: Artist requires wheelchair accessible entrance; no flash photography during performance; artist will provide backing tracks via USB drive
```

## Best Practices for Effective Riders

### For Artists

1. **Be Specific:** Vague requirements lead to misunderstandings. Instead of "good sound system," specify "full PA system with monitor speakers."

2. **Prioritize Essentials:** Distinguish between must-have requirements and nice-to-have preferences to help venues understand what's truly necessary.

3. **Update Regularly:** As your act evolves, update your rider to reflect current equipment and requirements.

4. **Consider Venue Size:** Adjust requirements based on venue capacity and capabilities. A small club has different resources than a large theater.

5. **Be Professional:** Use clear, courteous language and avoid excessive demands that might discourage bookings.

### For Venues

1. **Communicate Early:** Review the rider immediately upon receipt and flag any concerns within 48 hours.

2. **Ask Questions:** If requirements are unclear, ask the artist for clarification rather than making assumptions.

3. **Document Agreements:** Keep written records of all agreed-upon terms and any modifications.

4. **Prepare Thoroughly:** Ensure all requirements are met before the artist arrives. Last-minute scrambling reflects poorly on the venue.

5. **Confirm Day-Of:** Have a staff member confirm with the artist upon arrival that all requirements have been met.

## Common Rider Modifications by Venue Type

### Small Clubs (Capacity: 50-200)

- Minimal backline equipment (typically artist brings own)
- Shared dressing space acceptable
- Limited security needs
- Simpler technical setup

### Mid-Size Venues (Capacity: 200-1,000)

- Standard backline equipment provided
- Dedicated dressing room
- Basic security personnel
- Professional sound and lighting systems

### Large Theaters (Capacity: 1,000+)

- Full backline equipment and instruments
- Multiple dressing rooms with amenities
- Dedicated security team
- Advanced technical capabilities (lighting, projection, etc.)

## Dispute Resolution

If disagreements arise regarding rider requirements:

1. **Review Documentation:** Refer to the signed rider contract and any written confirmations.

2. **Communicate Directly:** Contact the other party to discuss the issue professionally.

3. **Document Everything:** Keep records of all communications and agreements.

4. **Seek Mediation:** If necessary, use Ologywood's dispute resolution process or involve a neutral third party.

5. **Learn for Future:** Use the experience to refine future rider contracts and communication processes.

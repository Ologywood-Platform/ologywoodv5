

### Published homepage performance sample

A non-mutating browser sample was collected from `https://www.ologywood.com/`. The navigation reported approximately 335 ms DOMContentLoaded, 339 ms load-event completion, 312 ms first paint, 528 ms first contentful paint, and cumulative layout shift 0.00. Largest Contentful Paint was unavailable in this single browser-console sample, so this is not a substitute for representative field data or a sustained performance run. Seven below-fold images initially had no loaded source because they were lazy; after scrolling through the page and allowing observers to settle, all 13 homepage images reported complete with nonzero intrinsic dimensions. Core Web Vitals remains an evidence-gathering item requiring repeated representative samples or production analytics before a full pass claim.
